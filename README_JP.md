# Sonora

*🌐 他の言語で読む: [English](README.md)*

Sonora は Flutter で構築された、プライバシーを最優先にしたローカル音楽プレイヤーです。Material 3 Expressive デザインを採用し、アルバムアートから動的にテーマカラーを生成します。ディレクトリベースのライブラリ同期とシームレスなバックグラウンド再生を実現しており、ファイルのコピーやアップロードは一切行いません。主な対象プラットフォームは Android で、Windows ビルドにも対応しています。

**現在のバージョン:** 1.6.0

> [!NOTE]
> **AI に関する注記:** このプロジェクトは Google の Antigravity エージェント型コーディングフレームワークを使用し、AI の支援のもとで全面的に構築されています。すべてのコード・アーキテクチャ・機能は、AI と人間のペアプログラミングを通じて設計・実装・改善されました。

## 機能

### ライブラリ & 同期

- **ディレクトリベースの同期**: 任意のフォルダを指定して、ファイルをアプリストレージにコピーすることなく音楽を直接再生できます。
- **増分同期**: ファイルサイズと更新タイムスタンプを利用して変更のないファイルをスキップし、再スキャンを高速化します。すべてのスキャン処理はバックグラウンドアイソレートで実行されるため、UI の応答性が維持されます。
- **即時起動**: 起動時にキャッシュされたライブラリデータをミリ秒単位で読み込み、メタデータと再生時間をバックグラウンドで非同期更新します。
- **幅広いフォーマット対応**: `.mp3`、`.m4a`、`.mp4`、`.aac`、`.flac`、`.ogg`、`.opus`、`.wav`、`.wma`、`.amr`、`.3gp`、`.ts`、`.mkv`、`.mid`、`.midi` などに対応しています。
- **ID3 メタデータ & アートワーク**: タグはバックグラウンドアイソレートで解析され、アルバムアートはディスクにキャッシュされて高速に読み込まれます。
- **歌詞の検出**: サイドカー形式の `.lrc` および `.txt` 歌詞ファイルを同期時に自動検出します。
- **手動 & 自動の再同期**: ライブラリの任意のタブでプルリフレッシュ、設定画面の「今すぐ同期」ボタン、および月次リマインダーバナー（30日間スヌーズ可能）による再同期に対応しています。
- **同期詳細パネル**: ライブラリの合計サイズ、検出されたオーディオフォーマット、ユニークなダイナミックテーマ数、歌詞同期済み曲数を表示します。
- **オンボーディング**: ようこそ画面・同期の説明・権限設定・フォルダ選択の4ステップで構成される初回起動フローを備えています。

### ライブラリブラウジング

- **4つのタブ**: 曲・アルバム（グリッド表示）・アーティスト・プレイリストの各タブを、折りたたみ可能なアプリバーの下に配置しています。
- **検索**: タブごとのリアルタイムフィルタリングと即時の件数表示に対応しています。
- **並べ替えオプション**: タイトル・アーティスト・再生時間・追加日・トラック数など、タブごとに独自の並べ替え順と昇降順トグルを設定できます。設定はアプリ再起動後も保持されます。
- **アルバム & アーティスト詳細画面**: ぼかしアートワーク背景・全曲再生/シャッフル再生アクション・ヒーロートランジション・アーティストアルバムカルーセルを備えています。
- **プレイリスト詳細**: ドラッグで並べ替え、再生/シャッフル、スワイプで削除、確認付き削除（お気に入りは保護）に対応しています。
- **クイックシャッフル**: 任意のタブヘッダーや詳細画面から1タップでシャッフル再生できます。
- **カスタムプレイリスト**: プレイリストの作成・名前変更・ドラッグアンドドロップによる並べ替え・確認付き削除が可能です。
- **お気に入り**: 曲のコンテキストメニューからトグル操作できる組み込みのお気に入りプレイリストと、再生中画面のアニメーション付きハートボタンを搭載しています。
- **曲コンテキストメニュー**: 次に再生・キューに追加・プレイリストに追加・プレイリストから削除・曲情報の表示・お気に入りの追加/解除の操作が可能です。
- **曲情報シート**: タイトル・アーティスト・アルバム・再生時間・ファイルパス・フォーマット・ビットレート・サンプルレート・ファイルサイズ・タイムスタンプを一覧で確認できます。
- **再生中トラックのハイライト**: 現在再生中の曲がライブラリ一覧内で視覚的に強調表示されます。

### 再生

- **フルトランスポートコントロール**: 再生/一時停止・次/前の曲・経過時間と残り時間付きのシークバー・シャッフル・リピート（オフ → 全曲 → 1曲）を搭載しています。
- **キュー管理**: 再生中画面の「次に再生」タブで、ドラッグによる並べ替え・スワイプで削除・タップでジャンプが可能です。
- **次に再生 & キューに追加**: 任意の曲メニューからトラックをキューの先頭または末尾に追加できます。
- **クイックシャッフル**: 1タップで現在のリストをシャッフルし、ランダムな開始トラックを選択してシャッフルモードを有効化します。
- **ボリュームスライダー**: 再生中画面にアプリ内ボリュームコントロールを搭載し、設定が保持されます。
- **スリープタイマー**: プリセット（5〜120分）またはカスタム時間から選択できます。キャンセル・通知アクションによる1分延長・最後の10秒間のフェードアウトに対応しています。デフォルト時間は設定で変更可能です。
- **関連トラック**: 再生中画面の「関連」タブに「このアルバムの他の曲」と「このアーティストの他の曲」が表示されます。
- **閉じても再生を続ける**: アプリをリセント画面から閉じた後も再生を継続するオプション設定です。

### 再生中 & UI

- **Material 3 Expressive デザイン**: Outfit・Inter フォント、円形コントロール、ぼかし背景アートワーク、カスタムスタイルのスライダーを採用しています。
- **グローバルミニプレイヤー**: ライブ進行バー付きの常時表示ボトムバーです。タップで展開、上下スワイプで開閉、左右スワイプでトラックをスキップできます。
- **再生中シート**: ぼかしアートワーク背景・トランスポートコントロール・タブコンテンツ（歌詞 / 次に再生 / 関連）を備えたフルスクリーンモーダルです。
- **イマーシブモード**: アルバムアートをタップすると全幅に拡大表示されます。設定はセッションをまたいで保持されます。
- **ダイナミックテーマ（Material You）**: アルバムアートからアクセントカラーをバックグラウンドで抽出します。ユニークなテーマ数は同期詳細にライブ抽出インジケーター付きで表示されます。設定でトグル可能です。
- **テーマモード**: システム・ライト・ダーク — 選択したモードが保持されます。
- **歌詞**: `.lrc` ファイルは自動スクロール・アクティブ行のハイライト・タップでシーク機能付きで同期表示されます。`.txt` ファイルはスクロール可能なテキストとして表示されます。アートワーク上のオーバーレイと専用の全画面タブを切り替えられます。
- **オーディオビジュアライザー**: 再生中画面の下部にアニメーション付きの波形バーをオプションで表示します。
- **アンビエントグロー**: 再生中にアルバムアートの背後でパルスする放射状のグロー効果を表示します。
- **マーキーテキスト**: テキストがはみ出した場合、曲名・アーティスト・アルバムのラベルがスムーズにスクロール表示されます。
- **スワイプジェスチャー**: アルバムアートを左右にスワイプしてトラックをスキップできます。
- **アーティスト & アルバムシート**: 再生中画面から直接アクセスできるクイックナビゲーションのボトムシートです。

### 統計

- **リスニングダッシュボード**: 設定からアクセスできる5ページのスワイプ式統計画面です。
- **概要**: 総リスニング時間・完全再生数・再生したアルバム/アーティスト/プレイリスト数・初めて再生した曲・最も再生した曲・ユニークな曲数・最もアクティブだった日を確認できます。
- **トップチャート**: 曲・アルバム・アーティスト・プレイリストのトップ5 — 各エントリーをタップして移動または再生できます。
- **統計のリセット**: 確認プロンプト付きでリスニング履歴をすべて消去できます。

### Android 連携

- **バックグラウンド再生**: フォアグラウンドサービスが音楽の再生を維持し、通知ドロワーとロック画面に再生・一時停止・スキップ・シークのメディアコントロールを表示します。
- **ミュートオーバーライド**: デバイスがミュートになっている場合にメディア音量をわずかに引き上げ、再生が無音にならないようにします。
- **権限フロー**: オーディオ・ストレージ（レガシー Android）・通知の各権限をガイド付きで設定できます。

### 設定

- **ライブラリ同期**: 同期フォルダの確認・変更、最終同期日時の確認、スキャン所要時間の確認が可能です。
- **再生**: 閉じても再生を続ける・ダイナミックテーマ・オーディオビジュアライザー・スリープタイマーのデフォルト時間を設定できます。
- **外観**: テーマモード・カラー設定・ビジュアライザースタイル・ローカル画像オプションを設定できます。
- **ライブラリの書式設定**: リスト内での曲名の表示方法を設定できます。
- **プライバシー & 権限**: 各権限の説明とデータ管理オプションを確認できます（詳細は下記参照）。
- **アプリ情報**: バージョン確認・オープンソースライセンス表示・すべての設定とライブラリキャッシュを消去してオンボーディングに戻るリセットオプションを提供しています。

## プライバシー & 権限

Sonora はプライバシーを核心に設計されています。各権限の用途は以下の通りです：

| 権限 | 用途 |
|---|---|
| **ストレージ、オーディオ & カバー画像** | 指定した音楽フォルダ内のオーディオトラックとローカルアートワーク（例：`artist.jpg` や `cover.png`）をスキャンするために使用します。Android では「フォト & メディア」へのアクセスとして表示されますが、Sonora は指定した音楽ディレクトリ内のファイルのみを読み取ります。個人の写真ギャラリー・カメラロール・プライベートな画像には**一切アクセスしません**。 |
| **通知 & フォアグラウンドサービス** | 通知ドロワーとロック画面にメディアプレイヤーのコントロールを表示するために使用します。アプリがフォアグラウンドにない状態で音楽をバックグラウンドで継続再生するには、フォアグラウンドサービスが必要です。 |
| **ウェイクロック** | 再生中にデバイスがスリープして音楽が途切れないようにします。 |
| **インターネット** | GitHub から最新リリースバージョンとチェンジログを取得し、アップデートをお知らせするためだけに使用します。 |

### あなたのデータはあなたのもの

Sonora は完全にオフラインで動作し、GitHub でのアップデート確認を唯一の例外として、外部サーバーには一切接続しません。すべてのリスニング統計・設定・再生時間データはデバイス上にのみ保存され、外部に送信されることはありません。

### データの削除

あなたには完全な管理権限があります。設定の「情報 & サポート」タブ下部にある **危険ゾーン** から、すべてのアプリ設定・統計・キャッシュをいつでも即座に消去できます。

## アーキテクチャ

Sonora は `go_router` によるナビゲーションを採用し、クリーンで疎結合なコンポーネント構造で構築されています：

```
lib/
├── models/
│   ├── song.dart           - 楽曲メタデータコンテナ
│   ├── playlist.dart       - プレイリストモデル
│   └── grouping.dart       - アルバム/アーティストのグループ化ヘルパー
├── providers/
│   ├── player_provider.dart - 再生・キュー・ライブラリ・テーマカラーの状態
│   └── theme_provider.dart  - テーマモードの設定
├── routing/
│   ├── app_router.dart     - GoRouter の設定とシェルルート
│   ├── app_routes.dart     - ルートパスの定数
│   └── app_navigation.dart - 型付きナビゲーションヘルパー
├── screens/
│   ├── home_screen.dart             - メインタブレイアウト（曲 / アルバム / アーティスト / プレイリスト）
│   ├── now_playing_screen.dart      - 歌詞・キュー・関連タブ付きのフルスクリーンプレイヤー
│   ├── album_detail_screen.dart     - アルバムのトラック一覧
│   ├── artist_detail_screen.dart    - アーティストのディスコグラフィー
│   ├── playlist_detail_screen.dart  - 並べ替え可能なプレイリストのトラック
│   ├── settings_screen.dart         - 同期フォルダ・テーマ・再生・アプリの設定
│   ├── stats_screen.dart            - リスニング統計とトップチャート
│   └── onboarding_screen.dart       - 初回起動フロー
├── services/
│   ├── audio_handler.dart    - AudioService バックグラウンドコントローラー
│   ├── music_scanner.dart    - ファイルシステムスキャナーとライブラリキャッシュ
│   ├── lyrics_service.dart   - LRC/TXT 歌詞の読み込みと解析
│   ├── stats_service.dart    - 再生時間と再生回数のトラッキング
│   ├── permission_service.dart - ストレージと通知の権限管理
│   └── volume_service.dart   - ネイティブボリューム管理
├── theme/
│   └── app_theme.dart        - Material 3 のテーマカラーとタイポグラフィ
├── utils/
│   ├── color_extractor.dart  - バックグラウンドでのアルバムアートカラー抽出
│   └── logger.dart           - ルートとデバッグのロギング
├── widgets/                  - 再利用可能な UI（ミニプレイヤー・シークバー・アルバムアート・ビジュアライザーなど）
├── app.dart                  - アプリのブートストラップとライフサイクル管理
└── main.dart                 - エントリーポイント
```

## 動作要件

- [FVM](https://fvm.app/) と Flutter **3.44.7**（`.fvmrc` で固定）
- Dart SDK **^3.12.2**
- Android SDK **24+**（コンパイル/ターゲット SDK 37）
- 接続済みの Android デバイスまたはエミュレーター

## はじめに

1. **リポジトリをクローンする:**

   ```bash
   git clone https://github.com/yurtemre7/sonora.git
   cd sonora
   ```

2. **固定された Flutter バージョンをインストールし、依存関係を取得する:**

   ```bash
   fvm install
   fvm flutter pub get
   ```

3. **静的解析を実行する:**

   ```bash
   fvm flutter analyze
   ```

4. **接続済みのデバイスまたはエミュレーターで実行する:**

   ```bash
   fvm flutter run
   ```

5. **デバッグ APK をビルドする** *（任意）*:

   ```bash
   fvm flutter build apk --debug
   ```

## リリース

`main` へのコミットメッセージに `release:` が含まれている場合（例：`release: 1.6.0`）、GitHub Actions によって自動的にリリース APK がビルドされます。バージョン履歴の詳細は [CHANGELOG.md](CHANGELOG.md) を参照してください。
